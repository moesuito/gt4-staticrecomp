# GT4Recomp 1.2.5

**More controller response choices, retaining RetroAchievements and the stable 1.2.4 base.**

## Install or update

- Download GT4Recomp-Setup-1.2.5.exe and run it, or use the launcher's stable update notification.
- The installer retains the existing game-data and per-user settings/save layout. Your own supported GT4 USA
  v2.00 disc image is still required. No game data is included.
- This release uses the legacy English-only launcher, as approved by the owner. Matching short notes are
  supplied in English and Brazilian Portuguese. Spec II and the newer multi-game/portable launcher are not
  included in this 1.2.x update.

## Controller improvements

- Choose seven response curves for analog controls. Four new choices join linear, quadratic and cubic:
  S-curve, smooth power, sublinear and logarithmic.
- Preview and saved control settings use the same curve formulas across the launcher and game.
- Preserve SDL3's standardized 0..32767 gamepad trigger range for DualSense and Xbox controllers; the reviewed
  integration avoids applying a raw signed-joystick conversion to gamepad triggers.
- Existing bindings, keyboard controls, normal gamepad support and the 1.2.4 RetroAchievements behavior remain.

## Scope and known limits

- No racing-wheel configuration page, wheel-to-gamepad bridge or new wheel feedback implementation is included.
  The previous private wheel test build was withdrawn before publication. Native Driving Force Pro recognition
  and game-generated wheel FFB remain separate planned work.
- No new renderer, frame skipping or measured performance improvement is claimed.
- The renderer remains the separately downloaded gt4-gs package. RetroAchievements requires an account and
  Internet access for online services and is supported only for GT4 USA v2.00 on this release line.
- Automated virtual-controller and mapping tests do not certify every physical controller, USB/Bluetooth
  connection or driver. No new real-account achievement-unlock or installer execution test is claimed.

## Build provenance

The program source is the reviewed controller-only PR #100 integration (#106, 8b73fa0), before wheel integration.
The native executable reuses the immutable slice1200-pcsx2.json build; its Windows file resource retains 1.2.4,
while the rebuilt launcher, installer and release identify 1.2.5. The distribution manifest and SHA256SUMS record
the exact package contents. No published 1.2.4 or 1.3.0 candidate assets are replaced.
