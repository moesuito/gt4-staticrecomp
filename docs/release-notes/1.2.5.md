# GT4Recomp 1.2.5

**More controller response curves and configurable racing-wheel inputs, preserving RetroAchievements from 1.2.4.**

## Install or update

- Download **GT4Recomp-Setup-1.2.5.exe** from this private draft and run it on the owner's test PC.
- This draft uses the final version number with no rc label. It is not offered by the public launcher updater.
- Once the owner publishes this release, the same installer can be downloaded publicly or offered by the stable updater.
- Existing game files, settings, controls, saves and replays use the existing installer/update preservation flow.
- Your own supported Gran Turismo 4 USA v2.00 disc image and the GSdx renderer are still required.
- This release keeps the single-game 1.2.x launcher and installer layout. Spec II, the multi-game launcher,
  interface language switching, frame skipping and a separate portable edition remain on the 1.3.0 line.

## Controller response curves

- Controls now offers seven response curves, adding S-curve, smooth power, sublinear and logarithmic choices
  to the existing linear, quadratic and cubic curves. Preview and saved settings use the same formulas.
- SDL Gamepad triggers keep the standardized zero-at-rest range for DualSense and Xbox controllers.
  The reviewed contribution does not apply a signed raw-joystick conversion to Gamepad triggers.
- Existing bindings, keyboard input and standard gamepad settings remain available.

## Racing-wheel configuration

- **Controls > Racing Wheel:** explicitly enable a wheel, select a device, inspect live readings and capture bindings.
- Configure steering rotation, deadzone, response and sensitivity; calibrate separate or combined pedals and choose
  the gamepad actions they drive. Bind paddles, buttons, hats and compatible auxiliary pedal/shifter devices.
- Presets provide starting templates for common device families. They are not a certification of physical compatibility.
- A wheel-owned device is excluded from ordinary gamepad input to avoid duplicate actions. Unrelated controllers and
  the keyboard remain usable. Missing or ambiguous selected devices produce neutral wheel input.
- Optional feedback adapts existing gamepad rumble, with a fixed driver centering spring where supported.
  Strength zero produces no force; focus loss, disconnect and shutdown stop feedback.
- Binding capture and live readings handle device disconnect/reconnect and identify auxiliary sources by device GUID.

## Review fixes and retained behavior

- Corrected wheel setting keys and actual launcher command payloads; exercised recorded UI settings through Rust.
- Corrected disabled defaults, explicit device selection, device ownership, disconnect routing and haptic cleanup.
- Restricted automatic detection to wheel identity rather than treating a whole vendor or an axis count as proof.
- Preserved the 1.2.4 RetroAchievements account revision guards, stale-response protection and cancelable HTTP shutdown.
- Automated coverage uses owned virtual controllers and a fake haptic output sink. Physical wheel/pedal behavior,
  USB/Bluetooth travel, feedback quality, real account services and installation remain owner acceptance checks.

## Requirements and known limits

- **Owner hardware testing is pending. Keep this release private until the owner accepts the result.**
- Wheel input maps to the game's existing gamepad actions. Native PS2 wheel USB identity/protocol, physics-derived
  steering torque, direct gear selection and a manual clutch signal are not implemented.
- Damper and feedback inversion are reserved file fields without a native effect; the interface does not offer them
  as active adjustments. Clutch readings are display-only. Identical GUIDs cannot distinguish two otherwise equal devices.
- RetroAchievements remains supported only for the original GT4 USA v2.00 target in this release. Internet access and
  an account are needed for online services. The later 1.3.0 port must keep it disabled for Spec II until validated.
- The owner approved keeping the legacy English-only interface for 1.2.5 on 2026-10-26. Short notes are supplied in
  English and Brazilian Portuguese; this launcher does not have the 1.3.0 embedded notes panel.
- No new renderer or measured performance improvement is claimed. Frame skipping is separate work for 1.3.0-rc7.
