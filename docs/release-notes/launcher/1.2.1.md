# GT4Recomp 1.2.1

**A cleaner install and updates that just work.**

## New
- GT4Recomp now installs in Program Files, for every user of the PC, in any folder you pick.
- Your settings and saves live in your Windows user folder; the big game files sit next to the program.
- Updates install silently: one confirmation, and the launcher reopens by itself.
- **Performance Mode** (Settings > Graphics): faster on weaker PCs, by skipping a few light effects.
- Settings now sits next to Play on the home screen.

## Fixes
- The launcher no longer opens as a blank white window on some PCs.
