# GT4Recomp 1.2.5

**More controller response choices and configurable racing-wheel inputs.**

## New

- Choose from seven controller response curves, including four new options.
- Set up steering, pedals and button bindings in Controls > Racing Wheel.
- Inspect live readings and use presets as starting points for calibration.
- Enable supported rumble and a fixed centering spring for your selected wheel.

## Fixes

- Wheel input no longer duplicates actions through the ordinary gamepad path.
- Disconnecting a wheel or leaving the game window stops its feedback.

## Good to know

- Physical wheel testing is pending; feedback uses gamepad rumble rather than steering forces from the car's physics.
- This update keeps RetroAchievements for USA v2.00 and the English interface; frame skipping and Spec II remain separate.
