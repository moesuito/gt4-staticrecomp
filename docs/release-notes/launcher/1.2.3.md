# GT4Recomp 1.2.3

**Quick fixes and a desktop shortcut.**

## Fixes
- The game no longer crashes at start for players who were not on GSdx.

## New
- Texture packs can go straight into the Textures folder, with no extra subfolder.
- The installer can create a **Gran Turismo 4** shortcut on your desktop.
- GSdx is now the only renderer; our own renderer, CoreGS 2.0, is coming later.
