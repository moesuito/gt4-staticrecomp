# GT4Recomp 1.2.4

**RetroAchievements for Gran Turismo 4 USA v2.00, contributed by JulioHeroZ.**

## Install or update

- Run **GT4Recomp-Setup-1.2.4.exe**, or accept the stable launcher update.
- If you installed the private 1.2.4-rc1 candidate, install this final version manually; the legacy updater uses the same numeric version for both.
- Existing game files, settings, controls, saves and replays are preserved by the existing installer/update flow.
- You still need your own supported Gran Turismo 4 USA v2.00 disc image and the GSdx renderer.
- This release uses the 1.2.3 single-game launcher and installer layout. The multi-game launcher, Spec II,
  language switching and the separate portable edition remain on the 1.3.0 branch.

## New

- **Settings > Achievements:** sign in to RetroAchievements, see account scores and Gran Turismo 4 achievement progress.
- **In-game notifications:** the native client evaluates achievement conditions once per guest VBlank and displays
  account/game banners, unlock notifications, achievement progress, challenge indicators and leaderboard trackers.
- **Session options:** enable or disable the integration, choose Hardcore mode, and use Encore mode to see already
  earned achievements trigger again. Options are applied to the next game session.
- The launcher stores the username and session token locally; it does not store the account password.

## Reliability fixes added during review

- A status request finishing after sign-out cannot restore the old credentials or overwrite newer session options.
- The Achievements page ignores stale responses after later actions or page navigation.
- Closing the game cancels an outstanding achievement HTTP request before joining its worker thread.
- Native achievement fixtures are registered in CTest, including a slow-loopback cancellation/restart test.
- Development UI checks cover the new tab, account states, options, sign-out and a delayed response after sign-out.

## Requirements and limits

- RetroAchievements integration in this release targets **GT4 USA v2.00 only**. Spec II is unsupported here and must
  remain disabled for RetroAchievements when this work is later integrated into 1.3.0, until separately validated.
- Internet access and a RetroAchievements account are needed for online account and achievement services.
- The interface remains English-only in 1.2.4 by owner decision on 2026-10-25; short release notes exist in both
  English and Brazilian Portuguese. This legacy launcher does not have the 1.3.0 embedded release-notes panel.
- Existing 1.2.3 known issues remain. No performance improvement or new renderer is claimed by this release.
- Automated fixtures do not replace validation of real login, unlock submission and visible notifications in gameplay.
