# GT4Recomp 1.3.0-rc7 (test build)

**A test release candidate of 1.3.0, combining RetroAchievements support from 1.2.4 and controller response curve improvements from 1.2.5.**

## What is new in rc7

- **RetroAchievements integration (Gran Turismo 4 NTSC-U v2.00):**
  - Sign in with your RetroAchievements username and Web API key via the launcher in **Settings > General > RetroAchievements**.
  - In-game achievement tracking and Rich Presence powered by the native `rcheevos` library.
  - Safe background credential handling with zero live credentials logged or stored in plain text.
  - Strict target isolation: RetroAchievements is enabled exclusively for the original Gran Turismo 4 v2.00 release and intentionally disabled for Spec II mod playthroughs.
- **Controller Response Curves (7 canonical options):**
  - Fine-tune analog steering and throttle/brake trigger response curves directly in **Settings > Controls**.
  - Seven canonical curves supported: **Linear**, **Quadratic**, **Cubic**, **S-Curve**, **Smooth Power** ($n^{1.5}$), **Sublinear** ($\sqrt{n}$), and **Logarithmic**.
  - Fully backward-compatible with legacy user configuration files and existing aliases (`scurve`, `smooth`, `root`, `log`).
  - Bit-accurate parity between native runtime physics driving (`controls.cpp`) and the launcher SVG preview visualizer (`controls-model.js`), verified across 8,960 input/deadzone test points.
- **Standardized SDL3 Gamepad Trigger Travel:**
  - Gamepad trigger inputs are normalized to the standardized range 0..32767 (quantized to 0..255), removing device-name-specific heuristics.
  - Consistent travel and rest thresholds across PlayStation (DualSense, DualShock 4), Xbox, and generic XInput/SDL controllers.
- **Two-Language Parity:**
  - All new RetroAchievements and controller response curve options and descriptions are fully translated in English (en-US) and Brazilian Portuguese (pt-BR).

## Install or update

- **Installer:** run `GT4Recomp-Setup-1.3.0-rc7.exe`. It is a per-machine install (one administrator prompt) and keeps your settings, saves, and replays.
- **Portable:** unpack `GT4Recomp-1.3.0-rc7-portable.zip` anywhere. Your data stays in that folder.
- **Updating from rc6 / earlier:** the launcher's normal update works; game executables are `gt4.exe` (Gran Turismo 4) and `gt4-spec2.exe` (Spec II).
- **Disc image requirements:** You need your own disc images: Gran Turismo 4 (USA, v2.00) for the original game, and your own Spec II 1.10 image for the mod. GT4Recomp ships no copyrighted game files.

## Known issues and limitations in this test build

- **Live server unlocks and physical controllers:** Automated verification was conducted using local synthetic fixtures, SDL virtual devices, and offline network mocks. Real gameplay steering feel, physical wheel bridges, and live achievement unlocks on public RetroAchievements servers remain for owner testing.
- **Spec II RetroAchievements:** Intentionally disabled and unmapped; RetroAchievements supports only the original Gran Turismo 4 v2.00 disc hash.
- **Graphics settings baseline:** The 13 known GS settings test expectations from rc6 remain documented as baseline behavior.
