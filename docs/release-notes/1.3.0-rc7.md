# GT4Recomp 1.3.0-rc7 (test build)

**A test release candidate of 1.3.0, combining RetroAchievements support from 1.2.4 and controller response curve improvements from 1.2.5.**

## What is new in rc7

- **RetroAchievements integration (Gran Turismo 4 NTSC-U v2.00):**
  - Sign in with your RetroAchievements username and password in **Settings > Achievements**.
  - Login obtains a session token from RetroAchievements; passwords are never saved.
  - The session token is protected at rest on Windows using Windows Data Protection API (DPAPI) with current-user scope (`token_protected` envelope in `retroachievements.toml`). Plaintext tokens are omitted from disk files and excluded from diagnostic exports.
  - Automatic, safe migration: existing plaintext configuration files from 1.2.4, 1.2.5 or early rc7 are automatically converted to the protected envelope on first access after verifying round-trip decryption. Original files are left completely untouched if protection or writing fails.
  - Portable install migration and machine isolation: because DPAPI tokens are bound to the local Windows user and machine, moving a portable installation folder to another computer or Windows user account keeps non-secret settings intact while displaying a clear "Re-login required" notice so you can reconnect your account.
  - In-game achievement tracking and Rich Presence powered by the native `rcheevos` library.
  - Strict target isolation: RetroAchievements is active exclusively for Gran Turismo 4 (SCUS-97328 v2.00) and disabled for Spec II mod playthroughs.
- **Controller Response Curves (7 options):**
  - Choose among 7 response curves in **Settings > Controls** (Linear, Quadratic, Cubic, S-Curve, Smooth Power, Sublinear, Logarithmic) to adjust steering and trigger input sensitivity.
  - Car physics and timing are unchanged; curves alter input mapping only.
  - Fully backward-compatible with legacy configuration files and aliases (`scurve`, `smooth`, `root`, `log`).
  - Mathematical parity between native C++ (`controls.cpp`) and the launcher SVG curve visualizer (`controls-model.js`), verified across 8,960 input/deadzone test points.
- **Standardized Gamepad Trigger Travel:**
  - SDL3 gamepad trigger inputs are normalized to 0..32767 (quantized to 0..255) across supported controllers without device-name heuristics.
- **Two-Language Parity:**
  - All new RetroAchievements and controller settings options and descriptions are translated in English (en-US) and Brazilian Portuguese (pt-BR).

## Install or test

- **Installer:** run `GT4Recomp-Setup-1.3.0-rc7.exe`. It is a per-machine install (one administrator prompt) and keeps existing user settings, saves, and replays in AppData.
- **Portable:** unpack `GT4Recomp-1.3.0-rc7-portable.zip` anywhere. User settings, saves, and data stay inside the folder.
- **Disc image requirements:** You need your own disc images: Gran Turismo 4 (USA, v2.00) for the original game, and your own Spec II 1.10 image for the mod. GT4Recomp ships no copyrighted game files.

## Known issues and limitations in this test build

- **Live server unlocks and physical controllers:** Automated verification used local synthetic fixtures, SDL virtual devices, and offline network mocks. Real gameplay steering feel, physical wheel bridges, and live achievement unlocks on public RetroAchievements servers remain for owner testing.
- **Spec II RetroAchievements:** Intentionally disabled and unmapped; RetroAchievements supports only the original Gran Turismo 4 v2.00 disc hash.
- **Credential security boundaries:** DPAPI protects the stored token at rest against offline disk inspection and other local Windows accounts. It does not protect against malicious processes running under the same Windows user session, memory inspection while the launcher is open, or token transmission to the game child process environment. If you downgrade the launcher to 1.2.x, the older version cannot read protected envelopes and will require a fresh login.
- **Graphics settings baseline:** The 13 known GS settings test expectations from rc6 remain documented as baseline behavior.
