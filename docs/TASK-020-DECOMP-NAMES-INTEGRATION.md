## 2. Symbol Resolution & Priority Strategy

In `docs/data/ee-names.csv`, 2,930 addresses possess multiple candidate symbol entries resulting from RTTI recovery, Adhoc script method registrations, vtable slot discovery, and Gran Turismo HD (`gthd`) lineage. To ensure unambiguous, reproducible symbol mapping, `scripts/ee_annotate.py` establishes a deterministic scoring hierarchy:

### 2.1 Scoring Model
1. **Quality Priority (Weight: +100):**
   - `named` (+100): Concrete, demangled function names (e.g., `GranTurismo4__GameObjectPS2__start`, `RaceBase::updateRace`).
   - `placeholder` (0): Ephemeral slots such as `CarIconMaker__virtual_01` or `func_001010E0`.
2. **Origin Priority (Weight: +10 to +20):**
   - `decomp` (+20): Verified against Gran Turismo 4 SCUS-97328 decompilation.
   - `adhoc` (+20): Registered in-engine script native methods (`Class::method`).
   - `gthd` (+10): Heuristic carried over from Gran Turismo HD.
3. **Tie-Breaker:**
   - Shorter names preferred over redundant prefixes.
   - Lexicographical ordering for strict determinism.
   - Secondary candidate names preserved as searchable `aliases`.

### 2.2 Empirical Resolution Examples
- **Address `0x001010E0`:**
  - Candidates: `CarIconMaker__virtual_01` (decomp, placeholder) vs. `GranTurismo4__GameObjectPS2__start` (gthd, named).
  - Selected Primary: `GranTurismo4__GameObjectPS2__start` (aliases: `['CarIconMaker__virtual_01']`).
- **Address `0x0011EDB8`:**
  - Candidate: `MLoggerControl::setTotalTime` (adhoc, named).
  - Selected Primary: `MLoggerControl::setTotalTime`.

## 3. Generated Code Annotation Contract

Generated code consists of 326 `unit_XXXX.cpp` files, each wrapping a 16 KiB address window with a dispatch switch statement.

### 3.1 Annotation Target Syntax
The annotation pipeline targets two key code structures without altering surrounding code:
1. **Dispatch Case Stmt:**
   ```cpp
   // Before:
           case 12u: goto L_001010E0;
   // Annotated:
           case 12u: goto L_001010E0; // GranTurismo4__GameObjectPS2__start
   ```
2. **Goto Target Label:**
   ```cpp
   // Before:
   L_001010E0:
       cpu.r[1] = 0;
   // Annotated:
   L_001010E0: // GranTurismo4__GameObjectPS2__start
       cpu.r[1] = 0;
   ```

### 3.2 Invariance & Producer Verification Contract
Because production builds rely on strict hash pinning of `ps2game.lib` and generated unit manifests (`docs/inputs/slice116-ee-producer-contracts.json`), annotation must be mathematically invariant:
$$\text{strip\_annotations}(\text{annotate\_source}(\text{source}, \text{names})) \equiv \text{source}$$

- **Preservation of Whitespace & Line Endings:** The annotator respects existing indentation and preserves CRLF (`\r\n`) or LF (`\n`) exactly.
- **Idempotency:** Re-running the annotator on previously annotated files causes zero drift and avoids duplicate comments.
- **Object Code Parity:** Stripping comments yields byte-identical source files; compiling annotated sources in Clang/MSVC produces identical COFF object machine code.

## 4. Diagnostics & Tooling Integration

### 4.1 CLI & Python API
`scripts/ee_annotate.py` provides both a programmatic library and CLI commands:
- **Symbol Lookup:**
  ```bash
  python scripts/ee_annotate.py lookup 0x001010E0
  ```
  Output:
  ```text
  Address:  0x001010E0
  Primary:  GranTurismo4__GameObjectPS2__start
  Quality:  named
  Kind:     func
  Origin:   gthd
  Aliases:  CarIconMaker__virtual_01
  ```
- **Batch Unit Annotation:**
  ```bash
  python scripts/ee_annotate.py annotate <path/to/units> --out <path/to/annotated>
  ```
- **Invariance Verification:**
  ```bash
  python scripts/ee_annotate.py verify-invariance <path/to/unit.cpp>
  ```

### 4.2 Runtime Diagnostics & Crash Reporting
When the guest EE execution encounters untranslated code, the runtime outputs:
```text
[ee] stopped after N frames, C cycles: no translated code at 0x00123456
```
Integrating `lookup_symbol` into the crash processing pipeline (`launcher/crates/gt4l-core/src/exit.rs` and debug probes) enables user-facing and developer diagnostics to report:
```text
Gran Turismo 4 stopped unexpectedly: no translated code at 0x00123456 (MRaceCourseMapFace::get_course_color).
```
