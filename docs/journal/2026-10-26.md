## TASK-124: startup failure diagnostics and vcruntime140_1.dll bundling (issue #107)

- Analyzed issue #107 report and log bundle from jannuk0101. The game failed to launch on both 1.2.4 and 1.3.0-rc5 with exit code -1073741515, and session game.log files were 0 bytes.
- Identified exit code -1073741515 as Windows NTSTATUS 0xC0000135 (STATUS_DLL_NOT_FOUND). The MSVC/clang-cl x64 build requires vcruntime140_1.dll for __CxxFrameHandler4 C++ exception handling, but scripts/make_distribution.py only bundled vcruntime140.dll, msvcp140.dll, and msvcp140_atomic_wait.dll. On systems without the Visual C++ 2015–2022 x64 Redistributable installed in System32, Windows loader aborts process initialization before main().
- Added vcruntime140_1.dll to CRT_DLLS in scripts/make_distribution.py and updated documentation in docs/DISTRIBUTION.md and native/THIRD_PARTY.md.
- Updated launcher/crates/gt4l-core/src/exit.rs to detect STATUS_DLL_NOT_FOUND (-1073741515) and present an actionable user message directing the user to install the Visual C++ 2015–2022 Redistributable (x64) and verify game files rather than directing to an empty game.log. Added unit test.
