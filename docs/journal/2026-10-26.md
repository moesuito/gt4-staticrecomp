## TASK-126: forward keyboard messages to PCSX2 GS child window for ReShade (issue #102)

- Investigated issue #102 where ReShade installed in data/gs/<version> does not respond to the Home (Pos1) overlay key.
- Root cause: In GT4_RENDERER=pcsx2 mode, the renderer runs out-of-process (gt4-gs.exe) with its display area embedded as a Win32 WS_CHILD window of game_window. To protect game controller and driving inputs from deactivation upon clicking the picture, 
ative/window.cpp explicitly retains focus on game_window (SetFocus(window)). Because Windows routes keyboard messages solely to the window with focus, the child window in gt4-gs.exe never received WM_KEYDOWN/WM_KEYUP/WM_CHAR messages.
- Fix: In 
ative/window.cpp, forward unhandled keyboard messages (WM_KEYFIRST..WM_KEYLAST) to direct child windows of game_window via asynchronous PostMessageW. This preserves full process isolation and responsiveness while allowing ReShade and other third-party overlays attached to gt4-gs.exe to receive hotkeys (like VK_HOME) and text input.
