## M10 — one-instruction-at-a-time interpreter

- Branch `m10-interpreter`: `Interpreter` executes decoded instructions over
  `GuestState` — fetch at the PC, decode, classify, execute, advance. Delay
  slots take effect after the slot; likely branches nullify the slot when not
  taken; JAL/JALR link pc+8 (JALR reads its target before writing rd); stops
  (unsupported, syscall, illegal delay slot) leave the PC in place and are
  stable when re-stepped.
- Fixture incident, recorded: the first run crashed with a modal abort dialog.
  A hand-encoded fixture word was `lui t0, 0x1000` instead of `lui t0, 0x10`,
  so a computed store address left the mapped region; the M9 memory model
  reported the address exactly, the fixture was fixed, and the test now routes
  CRT dialogs to stderr. Library behavior was correct throughout.
- Tests: 10/10 CTest with the new `ee_interpreter` fixtures; Python suite
  unchanged (37 collected, 31 run, 6 skip).
- Evidence: `docs/reverse-engineering/m10-interpreter.md`.
