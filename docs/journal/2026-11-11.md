# 2026-11-11

## TASK-106: `.chd` disc images (issue #90)

`gt4l-disc` gained a `chd` module on the `chd` crate (BSD-3-Clause): `ChdDisc` reads the plain 2048-byte sectors from
the compressed hunks, so setup identifies a `.chd` where the player keeps it, then decompresses it once into
`games\<id>\disc\<serial>.iso` (DVD CHDs hold the ISO; CD CHDs are frames of 2352+96 bytes, and the first track's
user data is read per track type). The copy is renamed into place only at the commit, is checked against the SHA-1 in
the CHD header, and a damaged, cut-short or unfinished CHD (no hunk map) is refused with a plain message; the free space
is checked first. Picker, the "Decompressing the image" row and both languages were updated. Tests: synthetic DVD and
CD CHDs of a synthetic game, cancellation, re-install, damaged and unfinished files, other disc kinds, a Spec II CHD,
and an opt-in cross-check with MAME's `chdman` 0.276 (DVD, cue/bin CD and ISO CD, all identical to the ISO).
Not run in game (this machine cannot): owner test with a real CHD of each game pending.

## Gameplay mods move into the bundle (owner, 2026-11-11)

The owner decided (Telegram) that gameplay modifications ship in the same bundle as the recompiled port: the H-shifter
with direct gear application, reverse as a gate position (R, N, 1, 2, ...), and a clutch pedal with a clutch system.
The original game already runs, so the project now also "plays around more": mods are opt-in, off by default, and with
every mod off the game is identical to the reference. Recorded as `docs/decisions/0073-mod-support-in-bundle.md`; the
`AGENTS.md` mission and game-patch rules were scoped accordingly (patches leave gameplay alone; mods change it, opt-in).

TASK-215 (H-shifter, clutch, direct gears) is now a mod task of this repository; its deep study (transmission/clutch
physics map, direct gear path, pedal input plumbing, PoC plan) is in progress on `task/215-hshifter-deep`.
