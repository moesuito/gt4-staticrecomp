# 2026-10-31

## TASK-141: European PAL (SCES-51719) support triage and diagnostic guidance (issue #128)

- Triaged community Issue #128 regarding support for the European release of Gran Turismo 4 (PAL `SCES-51719`).
- Problem & Player Expectation:
  - Players frequently arrive from emulator ecosystems (such as PCSX2) expecting that any regional PS2 ISO
    can be loaded and executed interchangeably.
  - When picking a European PAL image (`SCES-51719`), the launcher refused setup with "This disc is not supported yet."
- Technical Reality & Constraints:
  - GT4Recomp is an ahead-of-time (AOT) static recompilation of NTSC-U v2.00 (`SCUS-97328`). Its 326 translated C++ units
    in `ps2game.lib` were translated directly from that exact ELF.
  - PAL `SCES_517.19` has 0% address parity due to Multi-5 localization (English, French, German, Italian, Spanish),
    different compiler link structures, and an in-game 50Hz/60Hz selector. Calling unmapped PAL addresses halts
    immediately with "no translated code".
  - Host hooks (aspect ratio HUD anchors, 480p overrides, license demo guards) are mapped to v2.00 guest RAM offsets;
    applying them to PAL memory corrupts guest state.
  - Pacing calibration in `pacing.cpp` is built around 59.94/60 Hz NTSC clock; 50Hz VBlank requires dedicated pacing.
- Architecture Decision:
  - Recorded [Decision 0073](docs/decisions/0073-pal-sces51719-target-triage.md) and [PAL-SCES51719-STUDY](docs/PAL-SCES51719-STUDY.md).
  - Like Spec II (`SCUS-97436`, Decision 0072), European PAL (`SCES-51719`) cannot be supported by swapping ISOs into the
    NTSC-U engine. It requires a dedicated secondary/regional target build pipeline (decrypting `SCES_517.19`, generating
    ~330 PAL C++ units, re-targeting native hooks, and adapting 50Hz/60Hz pacing).
  - Priority remains Phase 2 (CoreGS 2.0); PAL is recorded as a planned secondary target for post-2.0.0.
- Launcher Diagnostics:
  - Updated `gt4l-disc::setup` to recognize known GT4 regional releases:
    - Europe: `SCES-51719` / `SCED-51719`
    - Japan: `SCPS-15055` / `SLPS-25450` / `SCPS-17001`
    - Korea: `SCKA-20001`
    - Asia: `SCAJ-30007` / `SCAJ-20101`
  - Replaced the generic "another region" text for these titles with clear, polite educational guidance explaining
    that GT4Recomp is an ahead-of-time static recompilation compiled specifically from the NTSC-U release, and that
    regional releases have different executable layouts requiring a separate target.
