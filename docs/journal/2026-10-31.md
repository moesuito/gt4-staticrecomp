# 2026-10-31

## TASK-053: Custom texture paths and PCSX2 texture folder reuse (Issue #95)

- Implemented support for configuring a custom texture directory in GT4Recomp launcher, resolving
  community feature request [#95](https://github.com/moesuito/gt4-staticrecomp/issues/95).
- Problem: High-resolution texture replacement packs for Gran Turismo 4 (e.g. Rice / PCSX2 community
  HD packs) commonly occupy 10 to 30 GiB. Requiring users to copy these into `<install>\data\Textures`
  wastes massive amounts of disk space.
- Solution & Implementation:
  - `gt4l_core::paths::DataDirs`: added `custom_textures: Option<PathBuf>` alongside methods
    `set_custom_textures` and `custom_textures()`.
  - Directory resolution priority in `dirs.textures()`:
    1. Environment variable `GT4_TEXTURES_DIR` (if set and non-empty).
    2. Explicit custom directory set via `set_custom_textures()` (from launcher `settings.toml`).
    3. Default directory `<data_root>\Textures`.
  - Configuration in `gt4l_core::config::ConfigFile`: added field `pub textures_path: Option<PathBuf>`.
    Parsed under sections `[install]`, `[folders]`, or `[paths]`, and rendered to `[install] textures_path`.
  - `gt4l_tauri::state`: loads `textures_path` from settings, resolves relative portable paths,
    configures `dirs.set_custom_textures(Some(resolved_path))`, and logs custom directory usage.
  - Renderer pass-through: when launching the PCSX2 GS backend (`gt4-gs.exe`), the resolved
    textures directory is populated in `gt4-gs.ini` under `[Folders] Textures`, seamlessly loaded
    by the PCSX2 texture cache.
- Verification:
  - Added unit test in `launcher/crates/gt4l-core/tests/textures.rs` verifying that setting a custom
    texture directory or defining `GT4_TEXTURES_DIR` overrides the default path.
  - Added test in `launcher/crates/gt4l-core/tests/settings_config.rs` verifying parsing and serialization
    of `textures_path`.
  - Verified test suite: `cargo test --manifest-path launcher/Cargo.toml -p gt4l-core` (123 tests passed, 0 failed),
    `cargo test --manifest-path launcher/Cargo.toml -p gt4controls` (21 tests passed, 0 failed).
