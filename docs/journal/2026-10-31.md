## TASK-053 / TASK-128: External Textures and Zero-Copy ISO Reuse Study (Issue #95)

- **Problem & Storage Footprint Analysis (Issue #95):**
  - Investigated issue reported by `@xraynet` requesting in-place ISO reuse and custom PCSX2 texture folder sharing to save disk space.
  - Calculated that default disc image copying (~5.3 GB per target) combined with HD texture packs (~10–15 GB) forces users to duplicate ~15 to 25 GB of identical data when migrating from or coexisting with PCSX2.
- **Architecture & Workaround Investigation:**
  - Evaluated current disc lifecycle (`gt4l_disc::setup`) and verified that `gt4.exe` accesses disc images purely with read-only file operations, meaning concurrent shared usage with emulators is completely thread/process-safe.
  - Documented immediate Windows workaround: NTFS directory junctions (`mklink /J "...\data\Textures" "D:\PCSX2\textures\..."`) which are transparently resolved by the Windows kernel for both Tauri and `gt4-gs.exe` with zero file duplication.
- **Engineering Design & Solutions:**
  - **Custom Texture Path (TASK-053):** Designed launcher configuration field `custom_textures_path` wired through `launch::Pcsx2Paths` to `gt4-gs.ini [Folders] Textures`, including native folder picker in Settings.
  - **Zero-Copy In-Place ISO (TASK-128):** Designed receipt schema v3 for `receipt.json` supporting `image.mode = "external"`, zero-copy setup mode, and disconnected drive validation in `check_installed`.
  - Authored comprehensive study document: [`docs/EXTERNAL-TEXTURES-AND-ISO-REUSE-STUDY.md`](docs/EXTERNAL-TEXTURES-AND-ISO-REUSE-STUDY.md).
