## TASK-125: SPU2 exponential release underflow fix for looping GT Auto service audio (Issue #104)

- Forensics and technical analysis authored in `docs/GT-AUTO-AUDIO-LOOP-ISSUE104-STUDY.md`.
- Analyzed upstream Issue #104 ("Oil Change/Car Wash Noise persists"):
  - Symptoms: bubbling and water spray sound effects continue playing in an infinite loop after car wash or oil change services in GT Auto.
  - The sound persists across all menus, the World Map, and subsequent race/time trial sessions, stopping only when the game executable is closed.
- SPU2 architecture and ADPCM looping mechanics:
  - SPU2 Core 0 and Core 1 have 24 hardware voices each.
  - Environmental effects like soapy foam bubbles and water jets are encoded as looping Sony ADPCM blocks (`flags & 2u`).
  - SPU2 voices with loop flags repeat indefinitely in hardware until Key Off (`KOFF`) triggers release and the envelope attenuates to absolute zero (`level <= 0`), which transitions the voice to `kOff`.
- Mathematical root cause identified in `runtime/src/iop/spu2.cpp`:
  - In `Envelope::step`, exponential release scales decrement via:
    `delta = delta * level / 0x8000;`
  - When `level` decays to low values (< 32-4096 depending on release rate shift), integer division truncates `delta` to `0`.
  - Once `delta == 0`, `level` stops decreasing and freezes at a faint non-zero residual value.
  - Because `level <= 0` is never reached, the voice never transitions to `kOff` and continues looping indefinitely.
- Resolution and implementation:
  - Added an underflow guard enforcing `if (delta == 0 && level > 0) delta = -1;`.
  - Pinned derivation in `scripts/prepare_spu2_envelope.py` with reversible roundtrip integrity checking against donor SHA256 (`84809a6a...`).
  - Added CMake option `GT4_SPU2_RUNTIME_SOURCE` in `native/CMakeLists.txt`.
  - Added CTest fixture `native/spu2_envelope_fixture.cpp` (`native_spu2_envelope`) validating all 32 ADSR release rates, level 0 underflow prevention, linear decrease, attack rates, and voice transition to `kOff`.
  - Added Python test suite `tests/python/test_spu2_envelope.py`.
