- Implemented clean-room solution for TASK-139:
  - `gt4l_core::gs_release`:
    - Added `extract_version` to parse semantic versions from filenames (e.g. `gt4-gs-1.2.1-windows-x64.zip`, `gt4-gs-v1.3.0.zip`), wrapping folders, or version text files.
    - Added `detect_version` inspecting filename, archive contents, and wrapping directory.
    - Added `install_from_archive` to unpack, verify that `gt4-gs.exe` exists and meets `MINIMUM_VERSION` (1.2.1+), and atomically stage/publish it to `%LOCALAPPDATA%\GT4Recomp\gs\<version>`.
    - Added comprehensive unit and integration tests.
  - `gt4l_tauri`:
    - In `commands::app_state`, exposed `renderer_installed: bool` and `renderer_version: Option<String>`.
    - Added command `install_renderer_archive` with native `.zip` file picker.
    - Added `updates::install_renderer_from_archive` updating `version.json` and logging.
    - Registered `install_renderer_archive` in `commands.list`, `capabilities/default.json`, and `main.rs`.
  - Frontend UI:
    - In `home.js`: when Play fails due to missing GSdx, opens a recovery dialog offering "Download GSdx" (which triggers `apply_update("renderer")` with progress notifications) and "Install from zip..." (invoking `install_renderer_archive`).
    - In `settings.js` (About tab): added "Install GSdx from zip..." button alongside "Check for updates".
    - Updated dev mock and documentation in `ui/dev/`.
