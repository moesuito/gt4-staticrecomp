# 2026-10-31

## TASK-142: Portable & standalone distribution triage (issue #132)

- Triaged community Issue #132 regarding request for standalone/portable distribution without Edge WebView2
  or Windows installer dependencies.
- Problem & Findings ([PORTABLE-STANDALONE-STUDY](docs/PORTABLE-STANDALONE-STUDY.md)):
  - User requested a standalone/portable version to avoid running Windows installers or installing Microsoft
    Edge WebView2.
  - The game engine (`gt4vulkan.exe`) is 100% native C++20 and Vulkan, with zero dependency on Edge WebView2.
    Its only external dependencies are Vulkan, SDL3, and bundled MSVC runtime DLLs.
  - Direct double-click execution of `gt4vulkan.exe` is currently blocked only by launcher-supplied command-line
    arguments and environment variables. This is the exact scope of planned [TASK-097](TASKS.md#task-097--self-sufficient-game-executable).
  - The launcher (`GT4Recomp.exe`) relies on Tauri/Edge WebView2. Embedding a Fixed Version WebView2 runtime would
    add ~180 MB compressed (~450 MB uncompressed), contradicting the user's desire for a lightweight package.
  - Existing portable foundation: The codebase already supports fully portable path resolution (`paths.rs`),
    storing data in `<install>\data` and user configurations in `<install>\user` (via `GT4RECOMP_USER_DIR`).
- Roadmap & Workaround:
  - Mapped Issue #132 to planned TASK-098 (portable zip package) and TASK-097 (self-sufficient game executable).
  - Documented direct batch script execution workaround for players running without WebView2 today.
