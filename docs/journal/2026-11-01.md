## TASK-052: Texture pack importer, mod store, and active view manager

- Implemented texture pack importer, mod store, and active view manager in `launcher/crates/gt4l-core/src/mods.rs` (completing core pipeline of TASK-051 and TASK-052), documented in `docs/TASK-052-MOD-IMPORTER-ACTIVE-VIEW.md`.
- Security & Input Validation:
  - Enforced strict Zip-Slip defenses in `check_zip_path_safety`: rejects parent directory traversals (`..`), drive letters, leading slashes, colons (NTFS ADS streams), and Windows reserved device names (`CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, `LPT1`–`LPT9`).
  - Mitigated Zip-Bombs: capped at 200,000 entries, 256 MiB per file, 20 GiB total uncompressed, and 200:1 compression ratio limit.
  - Stripped forbidden executables and scripts (`.exe`, `.bat`, `.cmd`, `.ps1`, `.vbs`, `.dll`, `.so`, `.sh`).
- Mod Store & Ingestion:
  - Supports `.zip` archives and loose directories.
  - Normalizes legacy PCSX2 structures (`SCUS-97328/replacements`, `textures/SCUS-97328`, bare `replacements`) and ignores `dumps/`.
  - Generates `gt4mod.toml` (schema 1) and SHA-256 integrity map (`files.lock.json`).
  - Staging and atomic commit into `mods/store/<id>/` with registry management in `mods.toml`.
- Active View Construction:
  - Builds `mods/active/textures/SCUS-97328/` using NTFS zero-copy hardlinks with copy fallback for virtual or non-NTFS drives.
  - Priority-based conflict resolution and tracking: highest-priority enabled mod wins shared texture keys.
- Verification:
  - Ran `cargo test --manifest-path launcher/Cargo.toml -p gt4l-core --lib`: 109 tests passed (4 new tests covering zip-slip, layout normalization, zip import, and active view priority resolution).
  - Launch contract tests passed (16/16).
